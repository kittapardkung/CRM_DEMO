# WULING CHONBURI — Video Style Standard

ใช้ค่าตามนี้ทุกคลิป ห้ามเปลี่ยนเองโดยไม่ได้รับคำสั่งจากผู้ใช้ ค่าสีและฟอนต์อ้างอิงจาก `src/app/globals.css` และ `src/app/layout.tsx` ของเว็บไซต์ (ถ้าเว็บเปลี่ยน ให้ถือเว็บเป็นต้นฉบับแล้วอัปเดตไฟล์นี้)

## 1. Tone & Manner
น่าเชื่อถือ ทันสมัย เป็นกันเอง — ตัวแทนจำหน่ายทางการที่คุยง่าย ไม่ตะโกนขาย
- ภาพสะอาด โปร่ง ข้อความน้อย ตัวเลขเป็นพระเอก
- 1 ฉาก = 1 ประเด็น, ฉากละ 3–5 วินาที (pacing ปานกลาง)
- ภาษาสั้น ตรง

## 2. สี
| บทบาท | ค่า |
|---|---|
| Ink (พื้นเข้มหลัก) | `#101F3D`, เข้มกว่า `#0C1C36` |
| ขาว / เทาอ่อน (พื้นสว่าง) | `#FFFFFF`, `#F2F4F7` |
| น้ำเงินแบรนด์ | `#1B3A6B` (อ่อนลง `#4C6FA6`, `#AFC5E4`) |
| **Lime (สีเน้น)** | `#C6F24D` |
| Lime เข้ม (ข้อความบนพื้นสว่าง) | `#6F8F10` |
| ข้อความรอง | `#8E97A6` |

กฎ:
- Lime ใช้ไม่เกิน 1–2 จุดต่อฉาก (ตัวเลขสำคัญ, ขีดเน้น, CTA)
- ห้ามใช้ Lime `#C6F24D` เป็นสีตัวอักษรบนพื้นสว่าง
- สลับฉากพื้นเข้มกับพื้นสว่างเพื่อให้จังหวะไม่เบื่อ

## 3. ตัวอักษร
- ฟอนต์เดียว: **Prompt** (ไทย+อังกฤษ) น้ำหนัก 300/400/500/600/700
- หัวข้อ 600, เนื้อหา 400 หรือ 300, ตัวเลขใหญ่ 700 พร้อม `font-variant-numeric: tabular-nums`
- **Kicker**: ข้อความเล็ก ตัวพิมพ์ใหญ่ letter-spacing ~0.26em อยู่เหนือหัวข้อ (เช่น `PROMOTION · OCT 2026`) เป็นลายเซ็นประจำ
- ขั้นต่ำแนวตั้ง 9:16: เนื้อหา ≥ 42px, หัวข้อ ≥ 72px

## 4. รูปทรง
- มุมโค้ง 12–20px; ป้าย/ปุ่ม CTA เป็นแคปซูล (border-radius 999px) พื้น Lime ตัวอักษร Ink
- เงานุ่ม `0 18px 48px rgba(16,28,51,.14)`
- ไอคอนเป็น line icon เส้นหนาเท่ากัน ไม่ใช้การ์ตูน
- เส้นเน้นบาง ๆ สี Lime แบบ draw-on

## 5. Motion Signature
| องค์ประกอบ | กำหนด |
|---|---|
| Easing | `cubic-bezier(0.22, 1, 0.36, 1)` ทุกการเคลื่อนไหว ห้าม bounce แรง |
| ความเร็ว | เข้า 0.5–0.6 วิ, ออก 0.3 วิ |
| ข้อความเข้า | fade + เลื่อนขึ้น 24px ทีละบรรทัด stagger 0.08 วิ |
| ตัวเลขสำคัญ | count-up ~1 วิ + ขีด Lime draw-on ใต้ตัวเลข |
| การ์ด/กล่อง | scale 0.95→1 + fade, เงาค่อย ๆ ชัด |
| ภาพรถ/ภาพนิ่ง | Ken Burns ช้า ๆ (scale 1.0→1.06 ตลอดฉาก) |
| **Transition ระหว่างฉาก** | แถบ Lime ปัดซ้าย→ขวา (wipe 0.4 วิ) แล้วเผยฉากใหม่ — ใช้ทุกคลิป เป็นลายเซ็นหลัก |
| Callout | เส้นชี้ draw-on + จุดกลม Lime ที่ปลาย |

ห้าม: glitch, สั่น, หมุน 3D, ทรานซิชันแปลก ๆ หลายแบบในคลิปเดียว

## 6. โครงคลิปมาตรฐาน
1. **Hook (0–3 วิ)** พื้น Ink + ตัวเลข/ประโยคเด็ดสี Lime ขนาดใหญ่
2. **Body** ฉากละ 3–5 วิ: Kicker + หัวข้อ + 1 ประเด็น
3. **Highlight** ตัวเลขสำคัญ (ราคา ดาวน์ ผ่อน) แบบ count-up
4. **CTA (3–4 วิ)** พื้น Ink + โลโก้ + แคปซูล Lime (เช่น "ลงทะเบียนทดลองขับ") + เบอร์โทร/LINE
5. **Outro** โลโก้ + เส้น Lime วาดใต้ชื่อ

## 7. เสียง
- BGM จังหวะสบาย Corporate Pop / Light Electronic ต่ำกว่าเสียงพูด ~20 dB (ducking)
- SFX เฉพาะ soft whoosh ตอน wipe และ soft pop ตอนตัวเลขขึ้น
- ซับไตเติลไทย Prompt สีขาว บนแถบ Ink โปร่งแสง อยู่ใน safe zone

## 8. สเปกไฟล์
- หลัก: 9:16 1080×1920 (Reels/TikTok/Shorts); รอง: 16:9 1920×1080
- 30 fps, ความยาว 30–60 วิ, ส่งออก MP4 (H.264, AAC)
- Safe zone แนวตั้ง: บน 250px, ล่าง 350px
- โลโก้: `public/assets/wuling-chonburi-logo.jpg`

## 9. ขั้นตอนทำงานทุกครั้ง
1. อ่านต้นทาง (PDF / ไฟล์เสียง / สคริปต์) แล้วสรุปประเด็นและตัวเลขสำคัญ
2. เขียน storyboard เป็นตาราง (ฉาก | วินาที | ข้อความ | กราฟิก | เสียง) ให้ผู้ใช้ตรวจก่อน
3. เรนเดอร์ตัวอย่างสั้นดูสไตล์ แล้วจึงเรนเดอร์เต็ม
4. ตรวจก่อนส่ง: สีตรงตารางข้างบน, ใช้ Prompt, มี wipe Lime, มี CTA และโลโก้, ข้อความอยู่ใน safe zone, ตัวเลขตรงกับต้นทาง
5. ห้ามแต่งตัวเลข ราคา หรือโปรโมชันเอง ใช้เฉพาะที่มาจากต้นทาง ถ้าไม่ชัดให้ถามผู้ใช้
